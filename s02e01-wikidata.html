Interface Otome game

Une liste de jeux de drague (otome games, visual novels romantiques pour filles) récupérée directement depuis Wikidata. Chaque jeu renvoie vers sa page, où l'on trouve ses informations.

Code SPARQL de la requête

#defaultView:Table
SELECT DISTINCT ?jeu ?jeuLabel ?site WHERE {
  SERVICE wikibase:mwapi {
    bd:serviceParam wikibase:endpoint "www.wikidata.org";
                    wikibase:api "EntitySearch";
                    mwapi:search "otome game";
                    mwapi:language "en".
    ?genre wikibase:apiOutputItem mwapi:item.
  }
  ?jeu wdt:P136 ?genre.
  OPTIONAL { ?jeu wdt:P856 ?site. }
  SERVICE wikibase:label { bd:serviceParam wikibase:language "[AUTO_LANGUAGE],fr,en". }
}
ORDER BY ?jeuLabel
LIMIT 100
